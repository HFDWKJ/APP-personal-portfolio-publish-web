# Published Personal Portfolio

Generated public website for the owner's portfolio. Site assets and language routes retain the published layout. The source repository owns implementation; this repository owns the generated deployment tree.

## Repository layout and content roles

Apply the [canonical auxiliary-directory catalog](https://github.com/HFDWKJ/MyProtocol/blob/8722d0d2279337d2e414bac90bf00663afc3d7d0/System-Conventions/Repository-Auxiliary-Directories.md). Custom support categories use a dot plus three lowercase letters and are created only when needed. The following classification preserves primary project content and required consumer interfaces.

| Path | Role and boundary |
| --- | --- |
| `.log/` | Dated execution evidence; existing receipt bodies are preserved. |
| `_astro/` | Existing browser, package or published-site resource paths retained; no deployment layout change. |
| `en/` | Existing browser, package or published-site resource paths retained; no deployment layout change. |
| `fonts/` | Existing browser, package or published-site resource paths retained; no deployment layout change. |
| `zh/` | Existing browser, package or published-site resource paths retained; no deployment layout change. |

Root README/AGENTS, licenses, version authorities, manifests and launch/configuration interfaces retain their supported locations. Private local data and existing runtime settings are not relocated or uploaded by this classification. Old paths and original hashes are recoverable from the dated migration receipt and its pinned source commit. This source/layout update does not establish deployment, device acceptance or automatic synchronization.
