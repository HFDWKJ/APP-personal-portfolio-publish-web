CONTEXT

The operational question

Shipment information needs to become consistent advance shipping notices and trade documents. Repeated manual preparation creates opportunities for inconsistent fields.

APPROACH

Scope & approach

The repository documents two independent routes to the same output: a local Python GUI and an Excel VBA workflow. Each can be used separately, fitting different desktop working habits.

OUTPUT

What the project contains

  • Structured ASN workbook
  • Contract, invoice, and packing-list workbook
  • Separate Python and VBA workflows

Evidence & limits

This case summary is based on the project README. The private desktop applications have not been executed as part of this portfolio build. No business data, measured savings, or production-performance claims are included.
