02 / INVOICE DATA WAREHOUSE

From spreadsheets to questions.

A local analytical warehouse that turns export-invoice files into queryable data.

SELECT insight FROM operations;

CONTEXT

The operational question

Invoice workbooks hold useful shipment information, but analysis across files needs a consistent grain, types, and traceable transformations.

APPROACH

Scope & approach

The documented design uses DuckDB, Python, and SQL with raw, staging, and mart layers. The fact grain is an invoice line item, with analysis views for shipment, destination, and data quality.

OUTPUT

What the project contains

  • A single local DuckDB database
  • Typed, de-duplicated invoice-line data
  • SQL views and notebook-based exploration

Evidence & limits

Architecture is documented in the source repository. Import idempotence and analytical outputs have not been independently tested for this portfolio. No invoice records are distributed here.
